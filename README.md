# Jet
Jet is a general purpose programming language that aims to strike a balance between ergonomics and performance. It was released in Oct 2026 and is currently in alpha.

**Quick Facts:**

- It supports both OOP and functional programming paradigms
- The syntax is similar to Typescript and Swift
- Arrays and strings are dynamic
- Memory is automatically managed for you
- You have full control over how values get passed around (by value or by reference)
- Programs compile to native executable binaries
- LLVM is used as the compiler's backend
- The compiler front-end and IR layer are written by hand.
- AI was strictly used for learning purposes and to help make sense of obscure LLVM errors.

Here is a simple hello world program:
```
// main.jet
print("hello world");
```

```
$ jet ./main.jet # outputs ./main

$ ./main
hello world
```

Please visit [jet-lang.com](https://jet-lang.com) to learn more.
