# Jet Programming Language
Jet is a C-like general purpose programming language released in Oct 2026. It's currently in alpha. Please visit [jet-lang.com](https://jet-lang.com) to learn more.

```
// main.jet
print("hello world");
```

```
$ jet ./main.jet # outputs ~/main

$ ./main
hello world
```

### Download
At this time, the recommended way to download Jet's compilers is through the [Release Page](https://github.com/JetJet13/Jet/releases).
